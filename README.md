# 半日晴咖啡 SUNLIT HALF — 第一個接案網站練習

> **重要：本網站為虛構商家的作品集示範，不代表真實咖啡店。** 商品、價格、營業時間、地址與品牌故事皆為示範。

## 這個網站具備什麼？

- 100% 靜態網站：`index.html`、`styles.css`、`script.js`、本地 SVG 插畫
- 適合電腦、平板、手機的響應式排版
- 手機版選單與咖啡／甜點篩選
- 品牌介紹、完整菜單、理念、示範營業資訊、搜尋引擎說明文字
- 無額外套件、無 API、無後端、無任何客戶資料蒐集
- **全部插畫均為此練習專案用 SVG 程式碼製作**；不需外部圖片伺服器、付費字體或圖片素材

## 新手開啟方式（Windows）

1. 下載 ZIP，右鍵選「全部解壓縮」。
2. 開啟解壓縮後的資料夾，**雙擊 `index.html`**，就能在瀏覽器開啟網站。
3. 若需要本機伺服器，在該資料夾開啟 PowerShell，執行：
   ```powershell
   py -m http.server 8000
   ```
   再至瀏覽器開啟 `http://localhost:8000`；停止伺服器請按 `Ctrl+C`。
4. 修改網站前，先複製備份整個資料夾。

## ChatGPT 與 Codex 的分工

- **ChatGPT：** 了解客戶需求、設定範圍、決定版型與文案、審查結果。
- **Codex：** 在本機專案資料夾直接修改 HTML / CSS / JavaScript、檢查錯誤、整理交付檔案。
- **你：** 最後點開網站、測試手機與電腦、確認文案及資料、與客戶溝通。

### 如何使用 Codex

1. 解壓縮到 `D:\AI-Websites\sunlit-half-demo`（路徑只是範例，可自行選擇）。
2. 在你既有的 Codex 本機工作方式中，將這個資料夾設為工作資料夾／專案。
3. 貼上同資料夾的 `CODEX_PROMPT.md` 中的指令。
4. 要求 Codex 先閱讀專案、列出要改的地方，再實際改檔案。
5. 用瀏覽器開啟 `index.html` 人工核對，依 `QA_CHECKLIST.md` 驗收。

## 想修改內容的話

- 品牌名稱／文字／菜單／價格：`index.html`
- 色系、字體、間距、手機版：`styles.css`
- 手機導覽與菜單篩選：`script.js`
- 圖片：`assets/` 裡的 `.svg`

## 免費發布「作品集示範」

1. 在 GitHub 新建一個 **public** repository，例如 `sunlit-half-portfolio`。
2. 將 `index.html`、`styles.css`、`script.js` 及 `assets/` 上傳到 repository 根目錄（維持相對路徑）。
3. 進入 repository 的 **Settings → Pages**。
4. **Build and deployment → Source → Deploy from a branch**。
5. 選 `main` 分支與 `/(root)` 資料夾，儲存。
6. 到 Pages 設定頁查看 GitHub 顯示的正式網址，再用手機與桌機檢查。

⚠️ GitHub Pages 適合靜態**展示／作品集**，官方不允許把它當免費電商、交易網站或主要營運的商業主機。交付正式商用網站時，應與客戶選擇合適的託管服務、網域和維護方式。

## 真正接案前必須補強

- 把全部示範品牌、菜單、價格、地址、營業時間換成客戶核准的資料；移除作品集標示只限真實、已取得品牌使用授權的網站。
- 圖片要有使用權（本示範使用自製 SVG，真實客戶可改為客戶授權照片）。
- 決定真正的 CTA（LINE／電話／表單）並測試連結；若需要表單則評估個資保護、資安和後端成本。
- 確認網站正式發布的責任歸屬、網域所有權、改版次數、交付與維護費用。
- 請客戶確認所有文案與商品資料；不要杜撰好評、營業資訊、認證或服務承諾。
